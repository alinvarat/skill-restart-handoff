# Startup prompt handling

Read only after an explicitly requested new-session launch. Use the `debian-desktop-control` skill before screen interaction; these are startup-only actions, not permission to operate the new session’s task.

4. **Startup prompts.** The user gave standing permission to always answer Yes to these startup prompts (confirm this with the user before relying on it). About 5–8 seconds after launch take a screenshot with `debian-desktop-control/scripts/quickshot.py` (screenshot only). **Bring the new tab to the front yourself** when the screenshot shows other windows (another app often covers it; the tab title reads `handoff-<time>`, or “เทอร์มินัล” while the startup prompt is open, and `ps` shows the `claude` process alive but no `~/.claude/sessions/<pid>.json` yet): `dctl.sh start`, `dctl.sh send "key Super_L" "wait 1.2" "shot @s /abs/ov.png"`, click the terminal window thumbnail in the overview, then `shot` again. Alt+Tab picks arbitrary windows, so use the overview. Answering the startup prompt is this step’s job; the user is told only when a “Never answer” case below applies. While the new tab shows a startup confirmation before the first message is handled (“Is this a project you trust?” / “Yes, I trust this folder”, the bypass-permissions notice, approving this project’s settings or MCP servers, and similar), read the screen, select the affirmative option and confirm it with the control daemon (`dctl.sh start`, then for example `dctl.sh send "key down" "wait 0.3" "key enter"`, then `dctl.sh stop`). Check in a screenshot which option is highlighted before pressing Enter, since its position varies. Repeat while a new startup prompt appears, at most 5 times.
   **Never answer, and tell the user instead:** a login, password, OTP or CAPTCHA; anything about payment; anything that would send data out, delete or overwrite something, or install or update software; any prompt after the session has started working on the first message; and anything unexpected you cannot read clearly. Type nothing else into the new tab.
